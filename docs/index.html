Cloodoo Package Repositories

Cloodoo is a multi-device TODO manager with real-time sync. See the project on GitHub for sources, documentation, and other downloads (macOS, Android, tarballs).

Fedora / RHEL (dnf)

sudo curl -o /etc/yum.repos.d/cloodoo.repo \
  https://atgreen.github.io/cloodoo/rpm-repo/cloodoo.repo
sudo dnf install cloodoo

Debian / Ubuntu (apt)

curl -fsSL https://atgreen.github.io/cloodoo/deb-repo/cloodoo-archive-keyring.gpg | \
  sudo gpg --dearmor -o /usr/share/keyrings/cloodoo-archive-keyring.gpg
sudo curl -o /etc/apt/sources.list.d/cloodoo.list \
  https://atgreen.github.io/cloodoo/deb-repo/cloodoo.list
sudo apt update && sudo apt install cloodoo
